# UPDATE GUIDE: Version 2 (With Role Selection)

## What's New

### Role Selection During Registration
- Users now choose their role (Doctor or Admin) when registering
- Automatic dashboard redirection based on role
- Admin can now add and manage both doctor and admin users

## Installation

1. Extract: `unzip organ_matching_system_v2.zip`
2. Install: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open: `http://localhost:5000`
